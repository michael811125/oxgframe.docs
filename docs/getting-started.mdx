## 內置第三方依賴庫

- 使用 [UniFramework](https://github.com/gmhevinci/UniFramework) (UniEvent, UniMachine, UniReference)。
- 使用 [UnityWebSocket](https://github.com/psygames/UnityWebSocket) (最佳 WebSocket 解決方案) **特別推薦**。
- 使用 [MirrorNetworking - Telepathy TCP](https://github.com/MirrorNetworking/Telepathy) (TCP 解決方案)。
- 使用 [MirrorNetworking - KCP2K](https://github.com/MirrorNetworking/kcp2k) (KCP 解決方案)。
- 使用 [DiskUtils by keerthik](https://github.com/keerthik/simple-disk-utils) (DiskUtils 解決方案)。

  - [PatchSettings](/docs/assetloader/API/Runtime/PatchSettings) (using OxGFrame.AssetLoader)
