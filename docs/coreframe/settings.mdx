## CodeBindingSettings 配置說明

可以自行客製化綁定規則，包含新增 TailName 對應綁定的組件。

![](/img/getting_started/latest/img_7.png)

通過右鍵創建配置文件 (Project 窗體內右鍵 -> Create -> OxGFrame -> Create Settings -> Create Code Binding Settings)。

![](/img/getting_started/latest/img_4.png)
