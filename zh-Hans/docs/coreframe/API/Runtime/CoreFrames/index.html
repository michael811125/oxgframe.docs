CoreFrames

重要 注意 提醒

Coding Style wiki​

CoreFrames 是 CoreFrame 模块的统一调用入口（Facade），以嵌套静态类提供 UIFrame（UI 窗口）、SRFrame（场景资源）、USFrame（Unity 场景）与 CPFrame（克隆 Prefab）四组接口，涵盖界面对象与场景的预加载、显示、关闭、隐藏、加载与卸载，底层与 AssetLoader 联动引用计数管理。

命名空间OxGFrame.CoreFrame
类型public static class
源码CoreFrames.cs
using OxGFrame.CoreFrame;

提醒 各子系统的管理器（UIManager、SRManager 等）会在首次调用时自动创建并常驻（DontDestroyOnLoad），无需事先在场景中创建。

注意 UIFrame 需要场景中存在与 UI Prefab 上 UISettings.canvasName 同名的 Canvas 对象，相关设置请参考 CoreFrame 介绍。

快速上手​

// 显示 UI（可同时传递数据给 UI 的 OnShow）
var ui = await CoreFrames.UIFrame.Show("PlayerUI");

// 关闭 UI
CoreFrames.UIFrame.Close("PlayerUI");

// 显示场景资源（SR）
await CoreFrames.SRFrame.Show("BattleField");

// 加载 Single 场景（无前缀 = Bundle 场景，使用 Address 名称）
await CoreFrames.USFrame.LoadSingleSceneAsync("MainScene");

// 从 Build Settings 加载场景（build# 前缀）
await CoreFrames.USFrame.LoadSingleSceneAsync("build#MainScene");

// 克隆 Prefab（CP），不再使用时直接 Destroy 即可
var cp = await CoreFrames.CPFrame.LoadWithCloneAsync<CPBase>("BulletCP");

通用规则​

名称前缀解析​

CoreFrames 内置解析器，依传入名称的前缀决定资源来源：

前缀适用子系统说明示例
res#UIFrame、SRFrame、CPFrame从 Unity 原生 Resources 加载资源（依 Resources 相对路径）。res#Prefabs/PlayerUI
build#USFrame从 Build Settings 的 Scenes In Build 列表加载场景。build#MainScene
无前缀全部默认从 Asset Bundle (YooAsset) 加载资源（直接使用可寻址名称 Address）。PlayerUI

资源包 (Package)​

各加载方法皆提供 packageName 重载：

  • 未指定 packageName：自动使用默认 Package（AssetPatcher.GetDefaultPackageName()）。
  • 指定 packageName：从指定的 Package 加载资源，适用于多 Package 分包管理。

群组 (groupId)​

UIFrame 与 SRFrame 支持多群组管理：通过 Show 打开的实例会记录 groupId（如大厅群组 UIs、战斗群组 UIs），批量操作（CloseAll、HideAll、RevealAll、CheckHasAnyHiding）依 groupId 筛选作用范围。框架内部常量定义如下：

常量值说明
DEFAULT_GROUP_ID0未指定 groupId 的重载，默认使用的群组 ID。
DO_ALL_GROUPS-1将 groupId 传入 -1 时，作用范围扩及所有群组（等同调用 ...ForAllGroups 系列方法）。

进度回调 (Progression)​

各加载方法的 progression 参数类型为 OxGFrame.AssetLoader.Progression：

public delegate void Progression(float progress, float currentCount, float totalCount);
  • progress：总进度（0 ~ 1）。
  • currentCount / totalCount：当前完成数量与总数量。

关闭、隐藏与销毁​

  • Close 走正规关闭流程（OnPreClose → OnClose）；Hide 仅禁用对象并标记隐藏（触发 OnHide），之后可由 Reveal 恢复显示（触发 OnReveal）。已 Close 的对象无法 Reveal。
  • Close 时是否销毁实例取决于：调用端传入 forceDestroy，或 Prefab 上勾选 allowInstantiate（多实例）／onCloseAndDestroy（关闭即销毁）。实例销毁时将自动联动 AssetLoader 卸载资源（引用计数）。
  • Prefab 上勾选 Exclude From Close All（whenCloseAllToSkip）／Exclude From Hide All（whenHideAllToSkip）的对象，会被 CloseAll / HideAll 跳过；改用 ...AndExcluded 系列方法可连同这些对象一并处理。

CoreFrames.UIFrame​

UI 窗口的统一操作接口。管理所有 UI 窗口，支持 Group 多群组管理（如大厅群组 UIs、战斗群组 UIs）、Stack 堆栈管理（同节点内自动控制显示排序）、反切（reverseChanges）与逐层关闭（allowCloseStackByStack）。UI 实例依 Prefab 上 UISettings 的 canvasName 与 nodeType，自动挂载至对应 Canvas 下的节点。

await CoreFrames.UIFrame.Show("LobbyUI", null, "LoadingUI", awaitingUIExtraDuration: 0.5f);

克隆 Prefab（Clone Prefab）的统一操作接口。专门管理从 Prefab 实例化（Clone）出来的小型对象，如掉落物（急救包、药草等）、子弹、UI 模板组件（物品 ICON 等）。特性是不再使用时直接 Destroy 即可——实例销毁时会自动联动 AssetLoader 卸载，确保资源引用计数正确，无需额外调用关闭接口。

参数类型说明

返回值

UniTask<T> — 克隆出的实例组件；加载失败（未找到资源）或实例上未找到 T 组件时返回 null。

说明

异步加载 Prefab 并实例化（Clone）。T 需为挂载于 Prefab 根对象上的 CPBase 组件（或其子类）。实例化后依序触发 OnCreate → InitFirst（绑定）→ OnShow。

注意
  • Prefab 主体 Active 为 true 时，克隆后自动触发 OnShow；为 false 时，实例保持禁用状态，需自行 SetActive(true) 才会触发 OnShow。
  • 每次克隆都会经过加载计数，实例销毁时自动抵扣。

提醒 不再使用时，直接 Destroy(instance.gameObject) 即可，会自动联动 AssetLoader 卸载资源。

示例

// 克隆子弹并挂载至枪口节点
var bullet = await CoreFrames.CPFrame.LoadWithCloneAsync<BulletCP>("BulletCP", muzzle.transform);

// 指定位置与旋转克隆掉落物
var drop = await CoreFrames.CPFrame.LoadWithCloneAsync<DropItemCP>("MedkitCP", dropPos, Quaternion.identity);

// 使用完毕，直接销毁（自动联动卸载）
Object.Destroy(bullet.gameObject);
