BundleConfig

重要 注意 提醒

Coding Style wiki​

BundleConfig 是 AssetLoader 模块的运行时核心设置与工具类，集中管理资源运行模式（PlayMode）、下载与加载参数等静态设置，并提供部署配置文件（CdnConfig）解析、CDN 端点路径组合与本地／内置路径定位等工具方法。

命名空间OxGFrame.AssetLoader.Bundle
类型public static class
源码BundleConfig.cs
using OxGFrame.AssetLoader.Bundle;

提醒 一般情况下，运行模式与 Preset Packages 由场景中 PatchLauncher 组件的 Inspector 设置配置，并在启动时自动写入 BundleConfig 的对应字段，无需手动指派。

枚举​

PlayMode​

public enum PlayMode
{
    EditorSimulateMode,
    OfflineMode,
    HostMode,
    WeakHostMode,
    WebGLMode,
    WebGLRemoteMode,
    CustomMode
}

资源运行模式。

名称值说明
EditorSimulateMode0编辑器模拟模式。无需实际构建 Bundles，在编辑器中直接模拟资源运行（仅供开发阶段使用）。
OfflineMode1离线模式。仅使用随包内置资源运行，不进行远端更新。
HostMode2联机模式。从 Host Server（CDN）检查版本并下载更新资源。
WeakHostMode3弱联网模式。基于联机模式，支持断网时回退至本地最后记录的版本继续运行（搭配 enableLastLocalVersionsCheckInWeakNetwork 参数）。
WebGLMode4WebGL 模式。仅使用 Web 服务器上的内置资源运行。
WebGLRemoteMode5WebGL 远端模式。支持从远端服务器（CDN）下载更新资源。
CustomMode6自定义模式。由开发者通过 YooAsset 初始化参数自行配置运行方式（不支持 Preset Packages 的自动初始化）。

BuildMode​

public enum BuildMode
{
    BuiltinBuildPipeline = 1,
    ScriptableBuildPipeline = 0,
    RawFileBuildPipeline = 2,
#if YOOASSET_3
    ArchiveFileBuildPipeline = 3
#endif
}

资源构建管线模式。

名称值说明
ScriptableBuildPipeline0可编程构建管线（SBP, Scriptable Build Pipeline）。
BuiltinBuildPipeline1内置构建管线（Built-in Build Pipeline）。
RawFileBuildPipeline2原生文件构建管线（Raw File Build Pipeline）。
ArchiveFileBuildPipeline3归档文件构建管线（Archive File Build Pipeline）。限 YooAsset v3（YOOASSET_3）。

提醒 YOOASSET_2 / YOOASSET_3 由框架依安装的 YooAsset 版本自动定义（无需手动设置），完整差异对照参考 YooAsset 版本兼容性。

提醒 Preset Package 上的 buildMode 设置仅在 EditorSimulateMode 下生效。

下载选项 (Download Options)​

名称类型默认值说明
maxConcurrencyDownloadCountint10同时并发下载数量。在创建下载器时作为默认并发数。
failedRetryCountint3下载失败重新尝试次数。在创建下载器时作为默认重试数。
breakpointFileSizeThresholduint20971520
（20 MB）		断点续传阈值（bytes）。文件大小达到阈值时启用断点续传（对应 YooAsset 文件系统参数 RESUME_DOWNLOAD_MINMUM_SIZE）。
DEFAULT_DOWNLOAD_WATCHDOG_TIMEOUTint30downloadWatchdogTimeout 的默认值。
downloadWatchdogTimeoutint30下载器看门狗监控超时时间。监控时间范围内未接收到任何下载数据时，直接终止该下载任务（对应 YooAsset 文件系统参数 DOWNLOAD_WATCH_DOG_TIME）。

加载选项 (Load Options)​

名称类型默认值说明
bundleLoadReadBufferSizeuint32768
（32 KB）		资源读取缓冲大小（AssetBundle.LoadFromStream）。
bundleDecryptReadBufferSizeuint32768
（32 KB）		资源解密读取缓冲大小。
autoUnloadBundleWhenUnusedboolfalse资源引用计数归零时，自动释放资源包（对应 YooAsset AutoUnloadBundleWhenUnused）。

处理选项 (Process Options)​

名称类型默认值说明
operationSystemMaxTimeSlicelong30异步作业系统每帧执行消耗的最大时间切片（毫秒，通过 YooAssets.SetOperationSystemMaxTimeSlice 应用）。
注意
  • autoUnloadBundleWhenUnused、breakpointFileSizeThreshold、downloadWatchdogTimeout 与 operationSystemMaxTimeSlice 在 Package 初始化阶段应用至 YooAsset，如需调整请在初始化流程前设置。
  • maxConcurrencyDownloadCount 与 failedRetryCount 在每次创建下载器时读取。

GetValueFromUrlCfg​

public static async UniTask<string> GetValueFromUrlCfg(string key)

参数

参数类型说明
keystring部署配置文件中的键名。可使用 PatchSettings.BUNDLE_IP、PatchSettings.BUNDLE_FALLBACK_IP、PatchSettings.STORE_LINK 常量。

返回值

UniTask<string> — 键对应的值；配置文件内容为空时返回 string.Empty；未找到键值时返回 null。

说明

从内置 StreamingAssets 读取部署配置文件（文件名由 PatchSettings 设置决定，默认 CdnConfig.dat）并解析键值数据，首次读取后会缓存解析结果。

注意 读取时自动检测文件头：若前 2 字节符合加密标记 PatchSettings.CIPHER_HEADER，将使用 PatchSettings.settings.bundleUrlCfgCipher 密钥自动解密后再解析。

示例

// 获取主要 CDN 地址（bundle_ip）
string host = await BundleConfig.GetValueFromUrlCfg(PatchSettings.BUNDLE_IP);

GetAppStoreLink​

public static async UniTask<string> GetAppStoreLink()

返回值

UniTask<string> — 主程序商店链接（部署配置文件中 store_link 键的值）；未找到时返回 null。

说明

从部署配置文件获取主程序商店链接（PatchSettings.STORE_LINK）。

GoToAppStore​

public static async UniTaskVoid GoToAppStore()

说明

获取商店链接（GetAppStoreLink）后，直接调用 Application.OpenURL 以系统浏览器打开主程序商店页面（Google Play / App Store），常用于强制更新流程。返回 UniTaskVoid（即发即弃，无需等待）。

示例

// 检测到主程序版本过旧，引导玩家前往商店更新
BundleConfig.GoToAppStore().Forget();

GetAppConfigFromStreamingAssets​

public static async UniTask<AppConfig> GetAppConfigFromStreamingAssets()

返回值

UniTask<AppConfig> — 内置的 AppConfig；读取失败时返回 null。

说明

从内置 StreamingAssets 读取 AppConfig（默认 AppInfo.json），内容包含 PLATFORM（平台）、PRODUCT_NAME（产品名称）、APP_VERSION（主程序版本）与 SEMANTIC_RULE（版号规则）。首次读取后会缓存。

GetAppConfigFromHostServer​

public static async UniTask<AppConfig> GetAppConfigFromHostServer()

返回值

UniTask<AppConfig> — Host Server 上的 AppConfig；无法获取时返回 null。

说明

从 Host Server 下载最新的 AppConfig（用于版本比对与组合最新版本路径）。首次读取后会缓存。

注意 下载失败时，若启用弱联网处理（playModeParameters.enableLastLocalVersionsCheckInWeakNetwork，仅弱联网模式适用），将回退使用本地存储的上次成功版本数据。

GetHostServerUrl​

public static async UniTask<string> GetHostServerUrl(string packageName)

参数

参数类型说明
packageNamestring资源包（Package）名称。

返回值

UniTask<string> — App Package 的远端下载端点 URL。

说明

依 Host Server 的最新 AppConfig 组合 App Package 的下载端点，格式如下：

<bundle_ip>/<rootFolderName>/<PRODUCT_NAME>/<PLATFORM>/<vX.Y[.Z]>/<packageName>

提醒 版本文件夹格式由 AppConfig 的 SEMANTIC_RULE 决定：PATCH 启用时为 v<Major>.<Minor>.<Patch>（如 v1.0.0），否则为 v<Major>.<Minor>（如 v1.0）。

示例

string url = await BundleConfig.GetHostServerUrl("DefaultPackage");
// 例：http://127.0.0.1/CDN/MyProduct/StandaloneWindows64/v1.0/DefaultPackage

GetFallbackHostServerUrl​

public static async UniTask<string> GetFallbackHostServerUrl(string packageName)

参数

参数类型说明
packageNamestring资源包（Package）名称。

返回值

UniTask<string> — App Package 的备用下载端点 URL。

说明

行为同 GetHostServerUrl，改以备用地址（bundle_fallback_ip）组合路径。

GetDlcHostServerUrl​

public static async UniTask<string> GetDlcHostServerUrl(string packageName, string dlcVersion, bool withoutPlatform = false)

参数

参数类型说明
packageNamestringDLC 资源包名称。
dlcVersionstringDLC 版本号（DLC 具有独立版本，不随主程序版本路径）。
withoutPlatformbool是否省略平台层级路径。
默认值：false

返回值

UniTask<string> — DLC Package 的远端下载端点 URL。

说明

组合 DLC Package 的下载端点，格式如下：

<bundle_ip>/<rootFolderName>/<PRODUCT_NAME>/<PLATFORM>/<dlcFolderName>/<packageName>/<dlcVersion>

withoutPlatform 为 true 时省略 <PLATFORM> 层级。

示例

string url = await BundleConfig.GetDlcHostServerUrl("Dlc01Package", "1.0.0");
// 例：http://127.0.0.1/CDN/MyProduct/StandaloneWindows64/DLC/Dlc01Package/1.0.0

GetHostServerAppConfigPath​

public static async UniTask<string> GetHostServerAppConfigPath()

返回值

UniTask<string> — 远端服务器上 AppConfig 的完整 URL。

说明

组合资源服务器上 AppConfig 配置文件的 URL（<bundle_ip>/<rootFolderName>/<PRODUCT_NAME>/<PLATFORM>/ 加上 AppConfig 文件名，默认 AppInfo.json）。

重要 会先读取内置（StreamingAssets）的 AppConfig 以确定当前产品名称与平台，再组合远端请求路径。

WriteInt16​

public static void WriteInt16(short value, byte[] buffer, ref int pos)

参数

参数类型说明
valueshort要写入的 16 位整数。
bufferbyte[]目标缓冲区。
posref int写入位置（写入后自动前移 2）。

说明

以 little-endian 字节序将 16 位整数写入缓冲区。主要用于部署配置文件加密文件头（PatchSettings.CIPHER_HEADER）的写入。

ReadInt16​

public static short ReadInt16(byte[] buffer, ref int pos)

参数

参数类型说明
bufferbyte[]来源缓冲区。
posref int读取位置（读取后自动前移 2）。

返回值

short — 读取的 16 位整数。

说明

从缓冲区当前位置读取 16 位整数（字节序依 BitConverter.IsLittleEndian 判断）。主要用于部署配置文件加密文件头的检测。
