## CodeBindingSettings 配置说明

可以自行定制化绑定规则，包含新增 TailName 对应绑定的组件。

![](/img/getting_started/latest/img_7.png)

通过右键创建配置文件 (Project 窗体内右键 -> Create -> OxGFrame -> Create Settings -> Create Code Binding Settings)。

![](/img/getting_started/latest/img_4.png)
