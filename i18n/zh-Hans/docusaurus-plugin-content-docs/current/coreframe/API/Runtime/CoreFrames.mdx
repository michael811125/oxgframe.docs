`CoreFrames` 是 **CoreFrame** 模块的统一调用入口（Facade），以嵌套静态类提供 `UIFrame`（UI 窗口）、`SRFrame`（场景资源）、`USFrame`（Unity 场景）与 `CPFrame`（克隆 Prefab）四组接口，涵盖界面对象与场景的**预加载、显示、关闭、隐藏、加载与卸载**，底层与 AssetLoader 联动引用计数管理。

|  |  |
| :--- | :--- |
| **命名空间** | `OxGFrame.CoreFrame` |
| **类型** | `public static class` |
| **源码** | [CoreFrames.cs](https://github.com/michael811125/OxGFrame/blob/master/Assets/OxGFrame/CoreFrame/Scripts/Runtime/Core/CoreFrames.cs) |

```csharp
using OxGFrame.CoreFrame;
```

<Highlight color="#00d679">提醒</Highlight> 各子系统的管理器（`UIManager`、`SRManager` 等）会在首次调用时自动创建并常驻（`DontDestroyOnLoad`），无需事先在场景中创建。

<Highlight color="#0373fc">注意</Highlight> `UIFrame` 需要场景中存在与 UI Prefab 上 `UISettings.canvasName` 同名的 `Canvas` 对象，相关设置请参考 [CoreFrame 介绍](../../intro.mdx)。

## 快速上手 {#quick-start}

```csharp
// 显示 UI（可同时传递数据给 UI 的 OnShow）
var ui = await CoreFrames.UIFrame.Show("PlayerUI");

// 关闭 UI
CoreFrames.UIFrame.Close("PlayerUI");

// 显示场景资源（SR）
await CoreFrames.SRFrame.Show("BattleField");

// 加载 Single 场景（无前缀 = Bundle 场景，使用 Address 名称）
await CoreFrames.USFrame.LoadSingleSceneAsync("MainScene");

// 从 Build Settings 加载场景（build# 前缀）
await CoreFrames.USFrame.LoadSingleSceneAsync("build#MainScene");

// 克隆 Prefab（CP），不再使用时直接 Destroy 即可
var cp = await CoreFrames.CPFrame.LoadWithCloneAsync<CPBase>("BulletCP");
```

## 通用规则 {#general-rules}

### 名称前缀解析 {#asset-name-prefix}

`CoreFrames` 内置解析器，依传入名称的前缀决定资源来源：

| 前缀 | 适用子系统 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| **res#** | UIFrame、SRFrame、CPFrame | 从 Unity 原生 **Resources** 加载资源（依 Resources 相对路径）。 | `res#Prefabs/PlayerUI` |
| **build#** | USFrame | 从 **Build Settings** 的 Scenes In Build 列表加载场景。 | `build#MainScene` |
| **无前缀** | 全部 | 默认从 **Asset Bundle (YooAsset)** 加载资源（直接使用可寻址名称 Address）。 | `PlayerUI` |

### 资源包 (Package) {#package}

各加载方法皆提供 `packageName` 重载：

- **未指定** `packageName`：自动使用默认 Package（`AssetPatcher.GetDefaultPackageName()`）。
- **指定** `packageName`：从指定的 Package 加载资源，适用于多 Package 分包管理。

### 群组 (groupId) {#group-id}

`UIFrame` 与 `SRFrame` 支持**多群组管理**：通过 `Show` 打开的实例会记录 `groupId`（如大厅群组 UIs、战斗群组 UIs），批量操作（`CloseAll`、`HideAll`、`RevealAll`、`CheckHasAnyHiding`）依 `groupId` 筛选作用范围。框架内部常量定义如下：

| 常量 | 值 | 说明 |
| :--- | :--- | :--- |
| **DEFAULT_GROUP_ID** | `0` | 未指定 `groupId` 的重载，默认使用的群组 ID。 |
| **DO_ALL_GROUPS** | `-1` | 将 `groupId` 传入 `-1` 时，作用范围扩及**所有群组**（等同调用 `...ForAllGroups` 系列方法）。 |

### 进度回调 (Progression) {#progression}

各加载方法的 `progression` 参数类型为 `OxGFrame.AssetLoader.Progression`：

```csharp
public delegate void Progression(float progress, float currentCount, float totalCount);
```

- `progress`：总进度（0 ~ 1）。
- `currentCount` / `totalCount`：当前完成数量与总数量。

### 关闭、隐藏与销毁 {#close-hide-destroy}

- **Close** 走正规关闭流程（`OnPreClose` → `OnClose`）；**Hide** 仅禁用对象并标记隐藏（触发 `OnHide`），之后可由 **Reveal** 恢复显示（触发 `OnReveal`）。已 Close 的对象无法 Reveal。
- Close 时是否**销毁实例**取决于：调用端传入 `forceDestroy`，或 Prefab 上勾选 `allowInstantiate`（多实例）／`onCloseAndDestroy`（关闭即销毁）。实例销毁时将自动联动 AssetLoader 卸载资源（引用计数）。
- Prefab 上勾选 **Exclude From Close All**（`whenCloseAllToSkip`）／**Exclude From Hide All**（`whenHideAllToSkip`）的对象，会被 `CloseAll` / `HideAll` 跳过；改用 `...AndExcluded` 系列方法可连同这些对象一并处理。

## CoreFrames.UIFrame {#uiframe}

UI 窗口的统一操作接口。管理所有 UI 窗口，支持 `Group` 多群组管理（如大厅群组 UIs、战斗群组 UIs）、`Stack` 堆栈管理（同节点内自动控制显示排序）、反切（`reverseChanges`）与逐层关闭（`allowCloseStackByStack`）。UI 实例依 Prefab 上 `UISettings` 的 `canvasName` 与 `nodeType`，自动挂载至对应 `Canvas` 下的节点。

### 属性 {#ui-properties}

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| ignoreTimeScale | `bool` | `false` | UI 系统的轮询计时是否忽略 `Time.timeScale` 影响（改用未缩放时间）。 |
| enableUpdate | `bool` | `true` | 是否驱动 UI 的 `OnUpdate` 轮询。 |
| enableFixedUpdate | `bool` | `true` | 是否驱动 UI 的 `OnFixedUpdate` 轮询。 |
| enableLateUpdate | `bool` | `true` | 是否驱动 UI 的 `OnLateUpdate` 轮询。 |

<Highlight color="#00d679">提醒</Highlight> 旧名称 `enabledUpdate` / `enabledFixedUpdate` / `enabledLateUpdate` 仍以 `[Obsolete]` 转发保留，建议改用新名称。

### SendRefreshData {#ui-sendrefreshdata}

```csharp
public static void SendRefreshData(RefreshInfo refreshInfo)

```

**参数**

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| refreshInfo | `RefreshInfo` | 刷新信息结构体，包含目标 UI 资源名称与要传递的数据：`new RefreshInfo(assetName, data)`。 |
| refreshInfos | `RefreshInfo[]` | 刷新信息数组（批量通知多个 UI）。 |

**说明**

向指定 UI 的**所有实例**发送刷新通知，触发其 `OnReceiveAndRefresh(data)`（显示中或隐藏中的实例皆会收到）。常用于**多语系切换**刷新、**接收服务端数据**后的显示刷新（如充值后刷新金额显示）等。

**示例**

```csharp
// 通知 PlayerUI 刷新金额显示
CoreFrames.UIFrame.SendRefreshData(new RefreshInfo("PlayerUI", newCoinAmount));
```

| progression | `Progression` | 加载进度回调。<br/>**默认值**：`null` |
| parent | `Transform` | 挂载的父节点。<br/>**默认值**：`null`（依 `uiSettings.nodeType` 自动挂载至 UICanvas 下的对应节点） |
| awaitingUIExtraDuration | `float` | 过渡 UI 的额外停留秒数。<br/>**默认值**：`0f` |

**返回值**

`UniTask<UIBase>` — 打开的 UI 实例组件（泛型重载返回 `UniTask<T>`）；加载失败（未找到资源）时输出错误日志并返回 `null`。

**说明**

加载并显示 UI，同时记录 `groupId` 供批量操作筛选。打开流程会依序触发 `OnPreShow` → `OnShow`。

<Highlight color="#0373fc">注意</Highlight>

- 同名 UI **已在显示中**且未勾选 `allowInstantiate` 时，不会重复打开，输出警告并直接返回现有实例。
- 启用 `reverseChanges`（反切）的 UI 打开时，会自动隐藏同 Canvas 反切堆栈中的前一个 UI；该 UI 关闭时自动恢复前一个 UI 的显示。

**示例**

```csharp
// 打开 UI 并传递数据
var ui = await CoreFrames.UIFrame.Show("PlayerUI", new PlayerData(100));

// 泛型打开，直接获取子类
var playerUI = await CoreFrames.UIFrame.Show<PlayerUI>("PlayerUI");

// 指定群组与 Package 打开
await CoreFrames.UIFrame.Show(1, "OtherPackage", "BattleUI");

// 打开前先显示过渡 UI（额外停留 0.5 秒）
await CoreFrames.UIFrame.Show("LobbyUI", null, "LoadingUI", awaitingUIExtraDuration: 0.5f);
```

## CoreFrames.SRFrame {#srframe}

场景资源（Scene Resource）的统一操作接口。用于管理场景中的 3D 资源（如 NPC、建筑、特效对象、场中需求的管理组件、AudioListener 等），操作逻辑与 `UIFrame` 相似（群组管理、Show / Close / Hide / Reveal、数据刷新），但不涉及 Canvas 节点与堆栈排序机制。实例默认挂载于 `SRManager` 节点下。

## CoreFrames.USFrame {#usframe}

Unity 场景（Unity Scene）的统一操作接口。增强型场景管理系统，封装 Unity 原生 `SceneManager` 的功能并扩展 **Bundle 场景**支持，支持 Single / Additive 多场景加载、主场景 + 子场景组合加载、进度合并上报、分帧激活根对象与场景卸载。

<Highlight color="#00d679">提醒</Highlight> 场景名称支持 `build#` 前缀：有前缀时从 **Build Settings** 加载，无前缀时从 **Asset Bundle (YooAsset)** 加载（参考[名称前缀解析](#asset-name-prefix)）。

## CoreFrames.CPFrame {#cpframe}

克隆 Prefab（Clone Prefab）的统一操作接口。专门管理从 Prefab 实例化（Clone）出来的小型对象，如掉落物（急救包、药草等）、子弹、UI 模板组件（物品 ICON 等）。特性是不再使用时**直接 `Destroy` 即可**——实例销毁时会自动联动 AssetLoader 卸载，确保资源引用计数正确，无需额外调用关闭接口。

### LoadWithCloneAsync\<T\> {#cp-loadwithcloneasync}

```csharp
public static async UniTask<T> LoadWithCloneAsync<T>(string assetName, Transform parent = null, uint priority = 0, Progression progression = null) where T : CPBase, new()
public static async UniTask<T> LoadWithCloneAsync<T>(string packageName, string assetName, Transform parent = null, uint priority = 0, Progression progression = null) where T : CPBase, new()
public static async UniTask<T> LoadWithCloneAsync<T>(string assetName, Transform parent, bool worldPositionStays, uint priority = 0, Progression progression = null) where T : CPBase, new()
public static async UniTask<T> LoadWithCloneAsync<T>(string packageName, string assetName, Transform parent, bool worldPositionStays, uint priority = 0, Progression progression = null) where T : CPBase, new()
public static async UniTask<T> LoadWithCloneAsync<T>(string assetName, Vector3 position, Quaternion rotation, Transform parent = null, Vector3? scale = null, uint priority = 0, Progression progression = null) where T : CPBase, new()
public static async UniTask<T> LoadWithCloneAsync<T>(string packageName, string assetName, Vector3 position, Quaternion rotation, Transform parent = null, Vector3? scale = null, uint priority = 0, Progression progression = null) where T : CPBase, new()
```

**参数**

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| packageName | `string` | 资源包名称。未指定时，使用默认 Package。 |
| assetName | `string` | Prefab 资源名称（Bundle 资源使用 Address 名称；支持 `res#` 前缀）。 |
| parent | `Transform` | 挂载的父节点。<br/>**默认值**：`null` |
| worldPositionStays | `bool` | 设置父节点时是否维持世界坐标（同 Unity `Instantiate` 语义）。 |
| position | `Vector3` | 实例的初始坐标。 |
| rotation | `Quaternion` | 实例的初始旋转。 |
| scale | `Vector3?` | 实例的初始缩放。<br/>**默认值**：`null`（保留 Prefab 原缩放） |
| priority | `uint` | 资源加载优先级。<br/>**默认值**：`0` |
| progression | `Progression` | 加载进度回调。<br/>**默认值**：`null` |

**返回值**

`UniTask<T>` — 克隆出的实例组件；加载失败（未找到资源）或实例上未找到 `T` 组件时返回 `null`。

**说明**

异步加载 Prefab 并实例化（Clone）。`T` 需为挂载于 Prefab 根对象上的 `CPBase` 组件（或其子类）。实例化后依序触发 `OnCreate` → `InitFirst`（绑定）→ `OnShow`。

<Highlight color="#0373fc">注意</Highlight>

- Prefab 主体 Active 为 `true` 时，克隆后自动触发 `OnShow`；为 `false` 时，实例保持禁用状态，需自行 `SetActive(true)` 才会触发 `OnShow`。
- 每次克隆都会经过加载计数，实例销毁时自动抵扣。

<Highlight color="#00d679">提醒</Highlight> 不再使用时，直接 `Destroy(instance.gameObject)` 即可，会自动联动 AssetLoader 卸载资源。

**示例**

```csharp
// 克隆子弹并挂载至枪口节点
var bullet = await CoreFrames.CPFrame.LoadWithCloneAsync<BulletCP>("BulletCP", muzzle.transform);

// 指定位置与旋转克隆掉落物
var drop = await CoreFrames.CPFrame.LoadWithCloneAsync<DropItemCP>("MedkitCP", dropPos, Quaternion.identity);

// 使用完毕，直接销毁（自动联动卸载）
Object.Destroy(bullet.gameObject);
```
