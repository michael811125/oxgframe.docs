`BundleConfig` 是 **AssetLoader** 模块的运行时核心设置与工具类，集中管理**资源运行模式（PlayMode）**、下载与加载参数等静态设置，并提供部署配置文件（`CdnConfig`）解析、CDN 端点路径组合与本地／内置路径定位等工具方法。

|  |  |
| :--- | :--- |
| **命名空间** | `OxGFrame.AssetLoader.Bundle` |
| **类型** | `public static class` |
| **源码** | [BundleConfig.cs](https://github.com/michael811125/OxGFrame/blob/master/Assets/OxGFrame/AssetLoader/Scripts/Runtime/Bundle/BundleConfig.cs) |

```csharp
using OxGFrame.AssetLoader.Bundle;
```

<Highlight color="#00d679">提醒</Highlight> 一般情况下，运行模式与 Preset Packages 由场景中 `PatchLauncher` 组件的 Inspector 设置配置，并在启动时自动写入 `BundleConfig` 的对应字段，无需手动指派。

## 枚举 {#enums}

### PlayMode {#playmode}

```csharp
public enum PlayMode
{
    EditorSimulateMode,
    OfflineMode,
    HostMode,
    WeakHostMode,
    WebGLMode,
    WebGLRemoteMode,
    CustomMode
}
```

资源运行模式。

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| EditorSimulateMode | `0` | 编辑器模拟模式。无需实际构建 Bundles，在编辑器中直接模拟资源运行（仅供开发阶段使用）。 |
| OfflineMode | `1` | 离线模式。仅使用随包内置资源运行，不进行远端更新。 |
| HostMode | `2` | 联机模式。从 Host Server（CDN）检查版本并下载更新资源。 |
| WeakHostMode | `3` | 弱联网模式。基于联机模式，支持断网时回退至本地最后记录的版本继续运行（搭配 `enableLastLocalVersionsCheckInWeakNetwork` 参数）。 |
| WebGLMode | `4` | WebGL 模式。仅使用 Web 服务器上的内置资源运行。 |
| WebGLRemoteMode | `5` | WebGL 远端模式。支持从远端服务器（CDN）下载更新资源。 |
| CustomMode | `6` | 自定义模式。由开发者通过 YooAsset 初始化参数自行配置运行方式（不支持 Preset Packages 的自动初始化）。 |

### BuildMode {#buildmode}

```csharp
public enum BuildMode
{
    BuiltinBuildPipeline = 1,
    ScriptableBuildPipeline = 0,
    RawFileBuildPipeline = 2,
#if YOOASSET_3
    ArchiveFileBuildPipeline = 3
#endif
}
```

资源构建管线模式。

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| ScriptableBuildPipeline | `0` | 可编程构建管线（SBP, Scriptable Build Pipeline）。 |
| BuiltinBuildPipeline | `1` | 内置构建管线（Built-in Build Pipeline）。 |
| RawFileBuildPipeline | `2` | 原生文件构建管线（Raw File Build Pipeline）。 |
| ArchiveFileBuildPipeline | `3` | 归档文件构建管线（Archive File Build Pipeline）。**限 YooAsset v3**（`YOOASSET_3`）。 |

<Highlight color="#00d679">提醒</Highlight> `YOOASSET_2` / `YOOASSET_3` 由框架依安装的 YooAsset 版本自动定义（无需手动设置），完整差异对照参考 [YooAsset 版本兼容性](./AssetPatcher.mdx#yooasset-compat)。

<Highlight color="#00d679">提醒</Highlight> Preset Package 上的 `buildMode` 设置仅在 `EditorSimulateMode` 下生效。

```csharp
public class CryptogramType
{
    public const string NONE = "NONE";
    public const string OFFSET = "OFFSET";
    public const string XOR = "XOR";
    public const string HT2XOR = "HT2XOR";
    public const string HT2XORPLUS = "HT2XORPLUS";
```

| XOR | `"XOR"` | `XOR, key` |
| HT2XOR | `"HT2XOR"` | `HT2XOR, hKey, tKey, jKey` |
| HT2XORPLUS | `"HT2XORPLUS"` | `HT2XORPLUS, hKey, tKey, j1Key, j2Key` |
| AES | `"AES"` | `AES, key, iv` |
| CHACHA20 | `"CHACHA20"` | `CHACHA20, key, nonce, counter` |
| XXTEA | `"XXTEA"` | `XXTEA, key` |
| OFFSETXOR | `"OFFSETXOR"` | `OFFSETXOR, key, dummySize` |

## 静态字段 {#fields}

#### 运行模式与 Preset Packages

| 名称 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| playMode | `PlayMode` | `PlayMode.EditorSimulateMode` | 当前资源运行模式。由 `PatchLauncher` 在启动时依 Inspector 设置写入。 |
| playModeParameters | `PlayModeParameters` | `null` | 当前运行模式的参数配置。由 `PatchLauncher` 依运行模式指派对应的参数对象。 |
| listAppPackages | `List<AppPackageInfoWithBuild>` | `null` | App Preset Package 列表（默认包裹）。由 `PatchLauncher` 写入。 |
| listDlcPackages | `List<DlcPackageInfoWithBuild>` | `null` | DLC Preset Package 列表（默认包裹）。由 `PatchLauncher` 写入。 |

#### 下载选项 (Download Options)

| 名称 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| maxConcurrencyDownloadCount | `int` | `10` | 同时并发下载数量。在创建下载器时作为默认并发数。 |
| failedRetryCount | `int` | `3` | 下载失败重新尝试次数。在创建下载器时作为默认重试数。 |
| breakpointFileSizeThreshold | `uint` | `20971520`<br/>（20 MB） | 断点续传阈值（bytes）。文件大小达到阈值时启用断点续传（对应 YooAsset 文件系统参数 `RESUME_DOWNLOAD_MINMUM_SIZE`）。 |
| DEFAULT_DOWNLOAD_WATCHDOG_TIMEOUT | `int` | `30` | `downloadWatchdogTimeout` 的默认值。 |
| downloadWatchdogTimeout | `int` | `30` | 下载器看门狗监控超时时间。监控时间范围内未接收到任何下载数据时，直接终止该下载任务（对应 YooAsset 文件系统参数 `DOWNLOAD_WATCH_DOG_TIME`）。 |

#### 加载选项 (Load Options)

| 名称 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| bundleLoadReadBufferSize | `uint` | `32768`<br/>（32 KB） | 资源读取缓冲大小（`AssetBundle.LoadFromStream`）。 |
| bundleDecryptReadBufferSize | `uint` | `32768`<br/>（32 KB） | 资源解密读取缓冲大小。 |
| autoUnloadBundleWhenUnused | `bool` | `false` | 资源引用计数归零时，自动释放资源包（对应 YooAsset `AutoUnloadBundleWhenUnused`）。 |

#### 处理选项 (Process Options)

| 名称 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| operationSystemMaxTimeSlice | `long` | `30` | 异步作业系统每帧执行消耗的最大时间切片（毫秒，通过 `YooAssets.SetOperationSystemMaxTimeSlice` 应用）。 |

<Highlight color="#0373fc">注意</Highlight>

- `autoUnloadBundleWhenUnused`、`breakpointFileSizeThreshold`、`downloadWatchdogTimeout` 与 `operationSystemMaxTimeSlice` 在 **Package 初始化阶段**应用至 YooAsset，如需调整请在初始化流程前设置。
- `maxConcurrencyDownloadCount` 与 `failedRetryCount` 在**每次创建下载器**时读取。

### GetValueFromUrlCfg {#getvaluefromurlcfg}

```csharp
public static async UniTask<string> GetValueFromUrlCfg(string key)
```

**参数**

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| key | `string` | 部署配置文件中的键名。可使用 `PatchSettings.BUNDLE_IP`、`PatchSettings.BUNDLE_FALLBACK_IP`、`PatchSettings.STORE_LINK` 常量。 |

**返回值**

`UniTask<string>` — 键对应的值；配置文件内容为空时返回 `string.Empty`；未找到键值时返回 `null`。

**说明**

从内置 `StreamingAssets` 读取部署配置文件（文件名由 [PatchSettings](./PatchSettings.mdx) 设置决定，默认 `CdnConfig.dat`）并解析键值数据，首次读取后会缓存解析结果。

<Highlight color="#0373fc">注意</Highlight> 读取时自动检测文件头：若前 2 字节符合加密标记 `PatchSettings.CIPHER_HEADER`，将使用 `PatchSettings.settings.bundleUrlCfgCipher` 密钥自动解密后再解析。

**示例**

```csharp
// 获取主要 CDN 地址（bundle_ip）
string host = await BundleConfig.GetValueFromUrlCfg(PatchSettings.BUNDLE_IP);
```

### GoToAppStore {#gotoappstore}

```csharp
public static async UniTaskVoid GoToAppStore()
```

**说明**

获取商店链接（[GetAppStoreLink](#getappstorelink)）后，直接调用 `Application.OpenURL` 以系统浏览器打开主程序商店页面（Google Play / App Store），常用于强制更新流程。返回 `UniTaskVoid`（即发即弃，无需等待）。

**示例**

```csharp
// 检测到主程序版本过旧，引导玩家前往商店更新
BundleConfig.GoToAppStore().Forget();
```

### GetAppConfigFromHostServer {#getappconfigfromhostserver}

```csharp
public static async UniTask<AppConfig> GetAppConfigFromHostServer()
```

**返回值**

`UniTask<AppConfig>` — Host Server 上的 AppConfig；无法获取时返回 `null`。

**说明**

从 Host Server 下载最新的 AppConfig（用于版本比对与组合最新版本路径）。首次读取后会缓存。

<Highlight color="#0373fc">注意</Highlight> 下载失败时，若启用弱联网处理（`playModeParameters.enableLastLocalVersionsCheckInWeakNetwork`，仅弱联网模式适用），将回退使用本地存储的上次成功版本数据。

### GetHostServerUrl {#gethostserverurl}

```csharp
public static async UniTask<string> GetHostServerUrl(string packageName)
```

**参数**

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| packageName | `string` | 资源包（Package）名称。 |

**返回值**

`UniTask<string>` — App Package 的远端下载端点 URL。

**说明**

依 Host Server 的最新 AppConfig 组合 App Package 的下载端点，格式如下：

```text
<bundle_ip>/<rootFolderName>/<PRODUCT_NAME>/<PLATFORM>/<vX.Y[.Z]>/<packageName>
```

<Highlight color="#00d679">提醒</Highlight> 版本文件夹格式由 AppConfig 的 `SEMANTIC_RULE` 决定：`PATCH` 启用时为 `v<Major>.<Minor>.<Patch>`（如 `v1.0.0`），否则为 `v<Major>.<Minor>`（如 `v1.0`）。

**示例**

```csharp
string url = await BundleConfig.GetHostServerUrl("DefaultPackage");
// 例：http://127.0.0.1/CDN/MyProduct/StandaloneWindows64/v1.0/DefaultPackage
```

### GetDlcHostServerUrl {#getdlchostserverurl}

```csharp
public static async UniTask<string> GetDlcHostServerUrl(string packageName, string dlcVersion, bool withoutPlatform = false)
```

**参数**

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| packageName | `string` | DLC 资源包名称。 |
| dlcVersion | `string` | DLC 版本号（DLC 具有独立版本，不随主程序版本路径）。 |
| withoutPlatform | `bool` | 是否省略平台层级路径。<br/>**默认值**：`false` |

**返回值**

`UniTask<string>` — DLC Package 的远端下载端点 URL。

**说明**

组合 DLC Package 的下载端点，格式如下：


`withoutPlatform` 为 `true` 时省略 `<PLATFORM>` 层级。

**示例**

```csharp
string url = await BundleConfig.GetDlcHostServerUrl("Dlc01Package", "1.0.0");
// 例：http://127.0.0.1/CDN/MyProduct/StandaloneWindows64/DLC/Dlc01Package/1.0.0
```

### WriteInt16 {#writeint16}

```csharp
public static void WriteInt16(short value, byte[] buffer, ref int pos)
```

**参数**

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| value | `short` | 要写入的 16 位整数。 |
| buffer | `byte[]` | 目标缓冲区。 |
| pos | `ref int` | 写入位置（写入后自动前移 2）。 |

**说明**

以 **little-endian** 字节序将 16 位整数写入缓冲区。主要用于部署配置文件加密文件头（`PatchSettings.CIPHER_HEADER`）的写入。

### ReadInt16 {#readint16}

```csharp
public static short ReadInt16(byte[] buffer, ref int pos)
```

**参数**

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| buffer | `byte[]` | 来源缓冲区。 |
| pos | `ref int` | 读取位置（读取后自动前移 2）。 |

**返回值**

`short` — 读取的 16 位整数。

**说明**

从缓冲区当前位置读取 16 位整数（字节序依 `BitConverter.IsLittleEndian` 判断）。主要用于部署配置文件加密文件头的检测。
