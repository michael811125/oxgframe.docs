## HotfixSettings 配置说明

可以自行定制化文件名称与扩展名称 (在 Resources 目录下)。

![](/img/getting_started/latest/img_6.png)

通过右键创建配置文件 (Project 窗体内右键 -> Create -> OxGFrame -> Create Settings -> Create Hotfix Settings in Resources)。

![](/img/getting_started/latest/img_4.png)
