## 编译 Hotfix DLL

前置作业记得 HybridCLR install (安装) -> [Generate/All](https://www.hybridclr.cn/docs/basic/buildpipeline#%E6%89%93%E5%8C%85%E6%B5%81%E7%A8%8B) (AOT 编译) -> 最后才能完成 Hotfix DLL 的编译。

<Highlight color="#ff2f00">重要</Highlight> HybridCLR 的编译方式请依照[官方文档](https://www.hybridclr.cn/docs/intro)进行操作。

## 创建 Hotfix Package

创建一个独立的 Package 进行相关 DLL 的收集。

![](/img/hotfixer/img_6.png)

<Highlight color="#0373fc">注意</Highlight> 这边的图片示例为独立 Package，如果想要使用单一 Package 进行开发收集也可以，视团队开发需求。

### 收集 Hotfix Main Scene

热更工程专用的主驱动场景。

![](/img/hotfixer/img_7.png)

<Highlight color="#00d679">提醒</Highlight> 流程概述：打包运行 AOT Main Scene -> 于 AOT 进行 Hotfix 后 -> 再加载 Hotfix Main Scene (驱动整个项目热更工程的后续阶段) -> 完成热更。

基本上项目 80 \~ 90% 以上皆为热更，甚至实现 AOT 业务逻辑的代码可能不到项目的 5 \~10%。
