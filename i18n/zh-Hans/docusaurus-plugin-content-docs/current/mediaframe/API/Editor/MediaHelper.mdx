`MediaHelper` 是 **MediaFrame** 的编辑器（Editor）辅助工具，用于输出媒体（Audio / Video）的 URL 配置文件，让客户端能动态解析音频与视频的来源地址。

|  |  |
| :--- | :--- |
| **命名空间** | `OxGFrame.MediaFrame.Editor` |
| **类型** | `public static class` |
| **源码** | [MediaHelper.cs](https://github.com/michael811125/OxGFrame/blob/master/Assets/OxGFrame/MediaFrame/Scripts/Editor/MediaHelper.cs) |

```csharp
using OxGFrame.MediaFrame.Editor;
```

<Highlight color="#0373fc">注意</Highlight> 本类仅供 **Unity Editor** 环境使用。

### ExportMediaUrlConfig {#exportmediaurlconfig}

```csharp
public static void ExportMediaUrlConfig(string audioUrlset, string videoUrlset, string outputPath)
```

**参数**

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| audioUrlset | `string` | 音频资源服务器 URL。传入空值时，使用默认值 `http://127.0.0.1/audio/`。 |
| videoUrlset | `string` | 视频资源服务器 URL。传入空值时，使用默认值 `http://127.0.0.1/video/`。 |
| outputPath | `string` | 配置文件输出的目录路径（输出文件名固定为 `MediaConfig.txt`）。 |

**说明**

将音频与视频的来源服务器 URL 输出成 `MediaConfig.txt` 配置文件至指定路径，通常输出至内置的 `StreamingAssets`，供客户端在使用 URL 播放模式时，动态解析音频与视频的来源地址。

输出内容包含 `#` 开头的说明注释，并以 **UTF-8** 编码写入，确保跨平台读取的兼容性：

```text
# audio_urlset = Audio Source Url Path
# video_urlset = Video Source Url Path

audio_urlset http://127.0.0.1/audio/
video_urlset http://127.0.0.1/video/
```

<Highlight color="#00d679">提醒</Highlight> 也可通过编辑器菜单 **OxGFrame → MediaFrame → Media Url Config Generator (MediaConfig.txt)** 打开窗口工具生成。

**示例**

```csharp
using OxGFrame.MediaFrame.Editor;
using UnityEngine;

MediaHelper.ExportMediaUrlConfig(
    "https://cdn.example.com/audio/",
    "https://cdn.example.com/video/",
    Application.streamingAssetsPath
);
```
