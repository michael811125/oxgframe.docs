## CodeBindingSettings Description

You can customize binding rules, including adding components corresponding to the TailName for binding.

![](/img/getting_started/latest/img_7.png)

Create the configuration file via right-click (Right-click in Project window -> Create -> OxGFrame -> Create Settings -> Create Code Binding Settings).
