### Method 2

**Direct Download Source Code ([Code Download ZIP](https://github.com/michael811125/OxGFrame))**

Copy the OxGFrame folder to the Assets folder of a new Unity project.

<Highlight color="#00d679">Reminder</Highlight> **If you don't need to modify the framework yourself, it is recommended to install directly using the Package Manager method**.

## Built-in Dependencies

- Using [YooAsset](https://github.com/tuyoogame/YooAsset) (powerful resource hot-update solution) **Highly recommended**.
- Using [UniFramework](https://github.com/gmhevinci/UniFramework) (UniEvent, UniMachine, UniReference).
- Using [UnityWebSocket](https://github.com/psygames/UnityWebSocket) (best WebSocket solution) **Highly recommended**.
- Using [DiskUtils by keerthik](https://github.com/keerthik/simple-disk-utils).

## Framework API

- [Hotfixers](/docs/hotfixer/API/Runtime/Hotfixers) (using OxGFrame.Hotfixer)
- [AssetLoaders](/docs/assetloader/API/Runtime/AssetLoaders) (using OxGFrame.AssetLoader)
- [AssetPatcher](/docs/assetloader/API/Runtime/AssetPatcher) (using OxGFrame.AssetLoader)
- [CoreFrames](/docs/coreframe/API/Runtime/CoreFrames) (using OxGFrame.CoreFrame)
- [MediaFrames](/docs/mediaframe/API/Runtime/MediaFrames) (using OxGFrame.MediaFrame)
- [NetFrames](/docs/netframe/API/Runtime/NetFrames) (using OxGFrame.NetFrame)

※Note: It is recommended to check the Examples of each module (pay attention to the usage rules of "res#" and "build#").

**Additional BuildTool writing can call**

- Editor
  - [HotfixHelper](/docs/hotfixer/API/Editor/HotfixHelper) (using OxGFrame.Hotfix.Editor)
  - [BundleHelper](/docs/assetloader/API/Editor/BundleHelper) (using OxGFrame.AssetLoader.Editor)
  - [MediaHelper](/docs/mediaframe/API/Editor/MediaHelper) (using OxGFrame.MediaFrame.Editor)

- Runtime
  - [BundleConfig](/docs/assetloader/API/Runtime/BundleConfig) (using OxGFrame.AssetLoader.Bundle)
  - [PatchSettings](/docs/assetloader/API/Runtime/PatchSettings) (using OxGFrame.AssetLoader)
    - PatchSettings.settings (**Singleton instance**)
  - [YooAssetBridge](/docs/assetloader/API/Runtime/YooAssetBridge) (using OxGFrame.AssetLoader.Bundle)
