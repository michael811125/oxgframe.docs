## HotfixSettings Description

You can customize the file name and extension (found under Resources).

![](/img/getting_started/latest/img_6.png)

Create the configuration file via right-click (Right-click in Project window -> Create -> OxGFrame -> Create Settings -> Create Hotfix Settings in Resources).
