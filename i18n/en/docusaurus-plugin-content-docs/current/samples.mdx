## Additional Notes

<Highlight color="#ff2f00">Important</Highlight> The sample project will use **Unity New InputSystem**, so it is recommended to install it first, otherwise there will be **EventSystem** failure issues.

<Highlight color="#0373fc">New Project</Highlight> **[Input System](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.8/manual/index.html)**

Install via Package Manager **(Install by name)**

```
com.unity.inputsystem
```
