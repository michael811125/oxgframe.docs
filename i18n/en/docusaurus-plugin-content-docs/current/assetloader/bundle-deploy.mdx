## Deploy Updated Assets

### Step 1.

App version configuration build.

Select OxGFrame -> AssetLoader -> Export Bundle And Config Generator from the MenuItem.

![](/img/assetloader/latest/img_9.png)

After opening, select **Export App Config To Streaming Assets** for the Operation Type, which will output the AppInfo.dat **(used for comparing the main program version)**.

![](/img/assetloader/latest/img_10.png)

### Step 2.

<Highlight color="#0373fc">Attention</Highlight> Confirm the default Packages on PatchLauncher.

- Preset App Packages.
- Preset DLC Packages.

![](/img/assetloader/latest/img_8.png)

### Step 3.

Select OxGFrame -> AssetLoader -> Export Bundle And Config Generator from the MenuItem.

![](/img/assetloader/latest/img_9.png)

After opening, select "Export Configs And App Bundles For CDN" as the Operation Type.

![](/img/assetloader/img_11.png)

1. <Highlight color="#0373fc">Attention</Highlight> The Source Folder is the folder where YooAsset exports the build.
2. <Highlight color="#0373fc">Attention</Highlight> The Packages to be exported, in the image, the exported package is DefaultPackage.
3. Finally, click Process to export.

Additionally, you can choose to export the folder based on the full version number, which helps avoid overwriting when uploading to the CDN.

![](/img/assetloader/latest/img_26.png)

### Step 4.

Upload the exported CDN folder directly to the cloud service to complete the resource deployment.

![](/img/assetloader/img_12.png)

### Step 5.

Configuration instructions for updating assets requests.

Select OxGFrame -> AssetLoader -> Bundle Url Config Generator (CdnConfig.dat) from the MenuItem.

![](/img/assetloader/latest/img_23.png)

The supported types are as follows **(the type will be automatically detected regardless of the output type)**:
- Cipher Process (Encrypted type) -> <Highlight color="#00d679">Reminder</Highlight> It is recommended to use this for Release deployments.
- Plaintext Process (Plaintext type).

After opening, configure the following related request information:
- CDN Server (Domain name or IP).
- App store link (**skip if not applicable**).

![](/img/assetloader/latest/img_25.png)

## Run-Package Deployment

Run-Package Grouping Definition (GroupInfo class).

```csharp
/// <summary>
/// Run-Package Grouping
/// </summary>
[Serializable]
public class GroupInfo
{
    [NonSerialized]
    public int totalCount;
    [NonSerialized]
    public long totalBytes;
    public string groupName;
    public string[] tags;
}
```

Tags in the YooAsset collector make it easy to distinguish between run-packages (if there are multiple Preset Packages, it will automatically detect if they contain the configured Tags and merge them).

<Highlight color="#ff2f00">Important</Highlight> This feature is only available for [Preset Packages](/docs/assetloader/settings/#preset-packages); independently initialized Packages do not support this feature.

![](/img/assetloader/latest/img_35.png)

Example of Run-Package Distinction:
- Minimum_Pack (Minimum Run-Package)
- Standard_Pack (Standard Run-Package)

![](/img/assetloader/latest/img_36.png)

<Highlight color="#0373fc">Attention</Highlight> groupName can be used for language localization tables, facilitating multi-language configurations, such as Key: Minimum_Pack, Value: Minimum Run-Package.

<Highlight color="#ff2f00">Important</Highlight> The record of the user's last selected group run-package will only be reset when an App version update is detected and the App needs to be updated.
